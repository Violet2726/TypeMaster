# 质量门禁

## 门禁规则

所有代码变更在合并到 main 之前必须通过以下质量门禁。

## 必须通过的门禁

### 1. 构建门禁
```bash
npm run build
```
- 必须成功完成
- 无警告或错误

### 2. 测试门禁
```bash
npm test
```
- 所有测试必须通过
- 不允许跳过测试

### 3. 依赖门禁
```bash
npm install
```
- 必须成功完成
- 不允许引入新的高危漏洞

## 可选门禁

### 覆盖率门禁
```bash
npm run test:coverage
```
- 建议覆盖率 > 70%
- engine 模块覆盖率应 > 80%

### Lint 门禁（如已配置）
```bash
npm run lint
```
- 无 lint 错误

## 门禁状态定义

| 状态 | 说明 |
|------|------|
| PASSED | 所有门禁通过 |
| FAILED | 至少一个门禁失败 |
| SKIPPED | 门禁未执行 |
| PARTIAL | 部分门禁通过 |

## 门禁检查时机

- 每日巡检任务：必须执行所有必须门禁
- 迭代任务：合并前必须执行所有必须门禁
- 紧急修复：至少执行构建和测试门禁

## 门禁失败处理

1. 立即停止当前任务
2. 分析失败原因
3. 修复问题
4. 重新执行门禁
5. 如果是架构问题，安排重构
