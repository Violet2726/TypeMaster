## 1. 今日主线
补齐“每日挑战”结果闭环，让用户完成挑战后立即看到名次、参与人数和个人最佳反馈。

## 2. 问题背景
上一轮已经把每日挑战前置到首页，但挑战结束后结果页仍然只有通用练习反馈，缺少排行榜与个人战绩反馈，激励链路在最后一步断开。

## 3. 根因判断
- 挑战成绩提交后没有在结果页消费排行榜信息
- 缺少挑战分数排序、个人最佳判断等可复用规则
- 端到端测试只验证“能开始挑战”，没有验证“打完挑战后获得反馈”

## 4. 目标用户价值
让用户完成一轮挑战后立刻知道自己排第几、打败了多少人、有没有刷新个人最佳，从而增强成就感和次日回访动机。

## 5. 工程价值
把挑战名次与个人最佳计算抽成纯逻辑，既便于测试，也为后续首页战绩预览和挑战页升级打基础。

## 7. 非目标
- 今日不重做 ChallengePage 视觉布局
- 不做实时多人排行或社交分享
- 不改云端 API 协议，只消费现有 fallback 能力

## 8. 设计方案
1. 抽出挑战分数比较与名次计算为纯函数
2. 在 challenge session 完成时乐观更新本地榜单，降低结果页等待感
3. 结果页新增“每日挑战战绩”卡片
4. 卡片展示：当前名次、参与人数、超过选手比例、个人最佳状态
5. 保留“查看挑战榜单”动作，把结果页和挑战页串起来
