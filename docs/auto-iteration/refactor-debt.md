# 技术债记录

## 说明

本文件记录项目中的技术债，包括已知问题和待重构项。

---

## 已知技术债

### 高优先级

#### 1. 性能优化：bundle 大小
- **问题**: 当前 bundle 大小约 300KB（gzip: 97KB），首屏加载时间较长
- **影响**: 用户体验
- **建议**: 分析依赖，使用动态导入，压缩图片资源
- **状态**: 待规划

#### 2. storage.js 测试缺失
- **问题**: localStorage 边界情况（QuotaExceededError、类型解析错误）无测试保护
- **影响**: 无人值守场景下静默失败
- **建议**: 建立单元测试基线，mock localStorage
- **状态**: ✅ 已关闭（2026-05-12 完成，45 个测试用例）

#### 3. ai-service.js 错误处理测试缺失
- **问题**: 错误归类逻辑（normalizeThrownError/throwResponseError）无测试
- **影响**: AI 服务异常场景无覆盖
- **建议**: 建立错误处理测试，mock fetch
- **状态**: 下周规划（主题 B）

### 中优先级

#### 4. 统一错误处理模式
- **问题**: 错误处理分散在各个模块，缺乏统一模式
- **影响**: 代码可维护性
- **建议**: 提取统一的错误处理中间件或工具函数
- **状态**: 待规划

#### 5. 类型定义补充
- **问题**: 当前代码缺乏类型定义，可维护性有限
- **影响**: 开发体验
- **建议**: 考虑引入 JSDoc 或 TypeScript
- **状态**: 待规划

#### 6. i18n 单文件臃肿
- **问题**: 566 行单文件，中英文文案硬编码，维护成本高
- **影响**: 新增文案容易只改一处导致不同步
- **建议**: 评估分层方案（按页面拆分或按语言拆分目录）
- **状态**: 下周评估（主题 C）

#### 7. practice-store.jsx 职责过重
- **问题**: 444 行，包含配置管理、AI 状态、教练状态、历史持久化
- **影响**: 可测试性和可维护性
- **建议**: 拆分大型 Context，评估状态分离方案
- **状态**: 待规划

### 低优先级

#### 8. 文档补充
- **问题**: 缺少 API 文档和组件文档
- **影响**: 新开发者上手难度
- **建议**: 添加 JSDoc 和 README
- **状态**: 待规划

#### 9. AI 服务超时边界情况
- **问题**: AI 服务超时的处理可能不完善
- **影响**: 用户体验
- **建议**: 全面审查超时处理逻辑
- **状态**: 待验证（可通过 ai-service.js 测试覆盖间接验证）

## 技术债清理规则

1. 新增功能时，如果发现相关技术债，应先清理技术债
2. 重构时，优先处理高优先级技术债
3. 每次迭代应至少处理一个技术债项
4. 技术债清理后应更新本文件和 decision-log.md
