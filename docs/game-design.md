# TypeRift 1.0 游戏设计

## 核心循环

1. First Rift 校准节奏，可跳过。
2. 大厅只给一个最重要的下一步。
3. 首字符锁定敌人；连续正确输入造成伤害。
4. 错误增加 Fracture、清空连击，并同时提供视觉与声音反馈。
5. 击杀提供战局经验与 Surge 能量。
6. 升级时从武器、遗物、符文中三选一；选择暂停模拟。
7. 区域末出现首领；远征可在第二区域后撤离。
8. 赛后立即生成确定性复盘，弱字符进入 Repair Trial。

## 模式

| 模式         |    时长 | 规则                               |
| ------------ | ------: | ---------------------------------- |
| First Rift   |  4 分钟 | 可跳过教学与基线校准               |
| Expedition   | 11 分钟 | 3 区域，每区 3 波与 1 首领         |
| Daily Rift   |  6 分钟 | 固定种子、Standard、服务端重放排位 |
| Repair Trial |   90 秒 | 最近弱字符专项词池                 |
| Quick Pulse  |   60 秒 | 移动端非排位触屏挑战               |

难度速度倍率为 Flow 0.85、Standard 1.0、Surge 1.15。Daily Rift 强制 Standard；反应时间辅助不进入排位。永久成长只包含 Resonance、Shards、内容解锁、36 项图鉴、18 项成就、每日/每周任务与非惩罚性活跃天数，不向排位注入永久战斗数值。

## 确定性

领域模拟使用 seed + 离散索引生成随机值，固定步长为 60Hz，单 tick 最大 50ms。渲染只读取 `RunState`，不参与命中、刷怪、结算或分数计算。`ReplayLog` 记录带战局毫秒时间的 `RunCommand`；相同内容版本、seed 与日志必须产生相同 `RunResult` 和 FNV-1a 结果哈希。

Daily Rift 提交必须同时满足：服务端已签发战局、未过期、seed/模式/难度/内容版本一致、客户端结果哈希自洽、服务端重放哈希相同。普通离线局本地立即结算，随后以客户端 run ID 幂等同步。
